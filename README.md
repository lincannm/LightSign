# LightSign｜轻签活动签到与匿名人数清点系统

LightSign 是一款面向**校园开放日、社团招新、技术沙龙、展览体验**等开放式活动的本地化签到与人数清点工具。

它旨在解决传统活动签到中“收集真实姓名或人脸照片存在隐私顾虑”与“纸质签到难以防重复和汇总”的两难问题，让活动组织者在**不采集实名信息、不保存人脸照片**的前提下，完成现场签到与到场人数清点。

---

## 核心功能与亮点

- **扫码代号签到（免实名）**：组织者一键生成带有效期的活动签到二维码；参与者连接同一局域网后扫码，填写自定义代号即可完成签到。系统自动拦截同一代号或同一浏览器的重复提交；代号已被别人占用时，页面会直接说明原因并允许换一个代号重新提交，不用重扫二维码。
- **匿名人数清点（全画面打码）**：组织者可通过照片或摄像头快速清点画面中的可见人脸。系统使用 OpenCV Zoo YuNet，仅框选检测位置并自动对全画面做马赛克处理，**不识别身份、不提取人脸特征、不保存原图**。
- **双端分离，开箱即用**：启动后自动开启“组织者管理端”和“参与者签到端”两个独立入口，自动识别本机局域网 IP 并配置 HTTPS 访问证书，无需手动改配置或额外安装数据库。
- **全本地运行，数据可控**：所有签到记录均保存在本机，支持一键导出 CSV / JSON 表格，随时撤销二维码或关闭活动。

## 快速启动（部署指南）

本项目在 Windows 下运行，内置所需检测模型与示例文件，无需额外下载模型或训练。新手推荐双击启动脚本，也可以选择手动部署。

人数清点使用 YuNet 完成人脸检测，模型、许可和哈希信息见 `models/`；合成数据评测协议见 `experiments/README.md`。

### 方式一：双击 START.bat（新手推荐）

1. **完整解压项目**：将项目解压到有读写权限的文件夹，不要在压缩包内直接运行。
2. **双击 `START.bat`**：首次使用请保持联网。脚本先检查 uv；没有 uv 时优先用本机已安装的 **Python 3.12** 创建项目内的 `.venv` 并安装依赖，无需手动激活环境。如果本机既没有 uv、也找不到 Python 3.12，脚本会停下来请你选择：**自动安装 uv**，还是**自己装好 Python 3.12 再重新运行**——不会擅自安装任何东西。
3. **打开组织者入口**：窗口显示服务入口后，在浏览器中打开组织者入口。启动日志会同时给出本机地址 `https://localhost:8503/` 和局域网地址 `https://<本机局域网IP>:8503/`（与签到入口使用同一个 IP），同一 Wi-Fi 内的电脑或手机用局域网地址也能打开。首次访问会有自签名证书提示，核对地址后点击“高级 -> 继续前往”；手机连接同一 Wi-Fi 后即可扫码签到。
4. **停止与再次启动**：使用期间保持窗口打开；按 `Ctrl + C` 停止服务，如出现“终止批处理操作吗”请选择 `Y`。以后仍然双击同一个脚本即可，已有环境会复用。

> - 无需管理员权限。选择自动安装 uv 时，uv 会装在 `%LOCALAPPDATA%\LightSign\bin`，脚本直接使用该路径，无需重新打开终端；Python 和依赖下载需要可用的网络。
> - 本机 Python 不是 3.12（例如 3.13、3.14）时，脚本不会拿它来建环境，而是按上面的方式先征求你的意见。
> - 防火墙弹窗请选择允许 Python 访问**专用网络**，参与者手机与电脑应连接同一局域网。

需要 HTTP 模式或自定义端口时，在项目目录打开命令行执行：

```powershell
.\START.bat --http
.\START.bat --organizer-port 9003 --participant-port 9004
.\START.bat --help
```

脚本参数会传给 `run.py`；切换模式或端口后，以启动窗口输出的实际访问地址为准。

---

### 方式二：使用 uv 命令启动（推荐）

**[uv](https://docs.astral.sh/uv/) 是一个用 Rust 语言编写的、速度极快的 Python 包和项目管理器。**uv 可以自动配置 Python 3.12 运行环境并安装全部依赖，无需手动创建虚拟环境。

**1. 安装 uv（电脑首次使用时执行一次）**

```powershell
winget install --id astral-sh.uv --exact
```

> 安装完成后请重新打开 PowerShell 窗口。若系统无 `winget`，可参考 [uv 官方安装说明](https://docs.astral.sh/uv/getting-started/installation/)。

**2. 启动项目（已配置清华镜像源加速下载）**

在项目根目录（`run.py` 所在目录）打开 PowerShell，执行：

```powershell
uv run --default-index https://pypi.tuna.tsinghua.edu.cn/simple .\run.py
```

首次运行会自动通过国内镜像源准备环境；后续再次启动可直接执行 `uv run .\run.py`。

---

### 方式三：使用原生 Python + pip 启动

如果电脑已按常规方式安装 **Python 3.12**（并已勾选加入环境变量 PATH），在项目根目录打开 PowerShell 依次执行：

> 只装好了 Python 3.12、没装 uv 时，直接双击 `START.bat` 也会自动完成下面的第 1、2 步。

```powershell
# 1. 创建并激活虚拟环境
python -m venv .venv
.venv\Scripts\Activate

# 2. 使用清华镜像源安装项目依赖
pip install -U pip -i https://pypi.tuna.tsinghua.edu.cn/simple
pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 启动服务
python .\run.py
```

> - 后续再次启动时，只需激活环境（`.venv\Scripts\Activate`）并执行 `python .\run.py`。

## 访问与使用流程

执行启动命令后，终端会同时启动两个独立服务并输出访问地址，组织者入口会同时列出本机与局域网两种地址：

| 角色入口 | 默认访问地址 | 功能说明 |
| :--- | :--- | :--- |
| **组织者管理端** | `https://localhost:8503/`（本机）<br>`https://<本机局域网IP>:8503/`（同一局域网） | 创建活动、生成/撤销签到二维码、匿名人数清点、导出签到记录（本机直接进入，局域网访问需输入登录口令） |
| **参与者签到端** | `https://<本机局域网IP>:8504/` | 手机或电脑扫码打开，填写代号完成签到（局域网内可访问，无管理权限） |

### 组织者登录口令

组织者管理端从局域网地址打开时会要求输入登录口令，本机 `localhost` 直接进入，不需要口令。

- 首次启动会在项目根目录自动生成 `PASSWORD.conf`，里面是随机口令，用记事本打开即可查看或修改；启动面板也会显示该文件名。
- 也可以自己创建 `PASSWORD.conf`，写入一行 `password = 你的口令`（纯文本一行或 `口令: 值` 也可以），口令至少 8 个字符。
- 修改口令后，新打开的登录页会立即使用新口令，已经登录的会话不受影响；重启服务会让所有登录会话失效。文件缺失时会在下次启动重新生成，文件里没有可用口令时启动会直接报错并说明原因。
- `PASSWORD.conf` 与 `local_data/`、`certs/` 一样只留在本机，不要上传或随项目外传。

### 4 步完成一场活动签到

1. **创建活动**：在本机浏览器打开**组织者管理端**（`https://localhost:8503/`，或启动日志中的局域网地址），输入活动名称并创建活动。
2. **展示二维码**：点击生成限时签到二维码，系统会自动将本机局域网地址写入二维码中，可直接投屏展示或下载图片分享。“二维码自动刷新”默认勾选，到期会自动生成新码；关闭后，过期二维码显示为黑色并提示“二维码已过期”，可手动重新生成。下载的 PNG 为静态图片，不会随页面自动刷新。
3. **参与者扫码签到**：参与者将手机连接到与电脑**同一个 Wi-Fi（局域网）**，用手机系统相机扫描二维码直接打开签到页面（也可在页面内选择摄像头扫码或上传二维码图片）。二维码在有效期内扫码成功后，当前会话有 5 分钟时间填写自定义代号并勾选自愿参加，期间原二维码自然到期不影响提交；系统会自动拦截同一代号或同一浏览器的重复提交。如果填的代号在本活动已被别人用过，页面会提示该代号已被使用并保留输入框，换一个代号再点提交即可。
4. **人数清点与导出**：活动期间可在“人数清点”标签中上传现场照片快速清点人数；活动结束后一键导出 CSV 或 JSON 格式的签到汇总记录（表格按北京时间显示中文表头，导出文件保留原字段名与 UTC 秒级时间戳）。

### 常见部署提示

- **关于浏览器安全提示**：首次启动时程序会自动在本机生成自签名 HTTPS 证书。由于该证书未向商业机构付费认证，浏览器首次打开时会提示“连接不是私密连接 / 证书不受信任”，点击**“高级 -> 继续前往”**即可正常使用，无需在手机或电脑上安装任何证书。
- **切换 Wi-Fi 后要重启项目**：如果电脑切换了网络导致局域网 IP 变化，按 `Ctrl + C` 停止程序并重新运行启动命令，系统会自动更新证书和二维码地址。
- **手机无法访问参与者端？**：请确认手机与电脑连接在同一 Wi-Fi 下（未开启 AP 隔离），且 Windows 防火墙允许 Python 通过局域网访问对应端口。如需切换为普通 HTTP 模式启动，可执行 `python .\run.py --http`（或 `uv run --locked .\run.py --http`）。

## 适用边界与隐私合规说明

1. **隐私优先设计**：本系统不采集真实姓名，不进行人脸身份识别或特征比对，不在后台保存上传的原始现场照片，界面仅展示全画面打码后的人数清点结果。
2. **适用场景**：本项目定位于**自愿参与、低风险的日常开放活动**（如讲座、沙龙、社团活动），旨在提供便捷的防误触重复签到与人数清点参考；**不适用于**考试点名、考勤考核、门禁安防等需要严格实名认证或防冒名顶替的高风险场景。
3. **测试数据合规**：项目内置的评测图像均由公有领域（Public Domain）单人图像经程序合成，仅用于验证软件工程与检测流程，不涉及任何真实自然人的隐私数据。
4. **本地数据保管**：程序运行期间生成的数据库与签名密钥保存在本地 `local_data/` 目录中（已配置 `.gitignore` 忽略），请勿将包含活动记录的 `local_data/` 或 `certs/` 目录上传至公开代码仓库。
5. **管理入口的访问范围**：组织者管理端默认同时监听本机与局域网，局域网访问需要 `PASSWORD.conf` 中的登录口令，本机 `localhost` 免登录，也没有按用户区分的账号权限。口令文件只留在本机，请勿外传；活动结束后按 `Ctrl + C` 停止服务，长期不使用时建议修改口令。如希望仅本机可访问，启动时加上 `--organizer-host 127.0.0.1`。
