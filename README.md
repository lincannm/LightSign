# 轻签活动签到与匿名人数核验系统

## 项目简介

LightSign 是一个基于计算机视觉技术的活动签到管理系统，专为自愿参加、无需实名的开放式活动设计，例如校园开放日、展览体验、技术交流会、兴趣小组聚会等场景。系统提供两大核心功能：一是基于限时二维码的自愿签到机制，支持代号化身份管理和防重复签到；二是基于人脸检测的匿名人数统计功能，在不识别具体身份的前提下快速获取现场人数，方便活动组织者记录参与情况。

我们特别注重隐私保护：签到过程中不保存人脸图像或生物特征模板，人数统计功能仅显示全画面马赛克效果。系统采用本地化部署，所有数据处理均在本地完成，确保活动组织者和参与者的隐私安全。

本项目包含完整的实验验证协议和性能评估脚本，适合作为计算机视觉课程的教学案例，也可直接用于实际的小型活动管理。

## 技术背景

LightSign 是参考 psesaank/FaceRecognitionAttendance 业务场景的独立重构实现。参考仓库 commit 980986f55e69bc5c6125ae81abf190af6755656a 未发现开源许可，本项目交付包不包含其源文件、模型或数据库，也不声称是其授权分支。我们在此基础上新增了活动限时签名二维码、活动内代号 HMAC 摘要、原子级去重机制、撤销与关闭功能、匿名检测以及全画面马赛克处理、固定合成实验协议等特性。需要说明的是，项目中使用的 HMAC、Haar 和 CLAHE 等方法均为成熟技术，并非本项目原创。

## 快速开始

本项目需要 Python 3.14 环境。模型和示例数据已经打包在项目中，无需额外下载或训练。

### 安装步骤

首先创建并激活虚拟环境，然后安装依赖：

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windows 用户请使用 .venv\Scripts\activate
python -m pip install -r requirements.txt
```

### 启动应用

在虚拟环境下执行：

```bash
python run.py
```

应用将在 http://127.0.0.1:8503/ 启动，在浏览器中访问即可使用。

### 使用流程

1. 创建活动
2. 生成限时二维码
3. 切换到”自愿签到”页面
4. 勾选同意声明并填写演示代号
5. 完成签到（重复提交会被拒绝）

二维码图片可以通过扫描解码或直接复制文本内容使用。匿名人数统计功能独立运行，不会关联签到身份信息，也不会将检测到的人脸框数量视为真实到场人数。系统支持导出 CSV 和 JSON 格式的签到台账。

## 实验复现

我们提供了完整的实验脚本，方便验证系统性能：

```bash
python scripts/check.py      # 系统功能检查
python scripts/evaluate.py   # 性能评估
python scripts/stress.py     # 压力测试
```

### 关于模型和数据

项目使用的是 OpenCV 预训练的 Haar 级联检测器，不需要额外训练。如果你想重新生成实验数据，可以先安装 scikit-image（`pip install scikit-image`），然后运行 `python scripts/make_data.py`。不过项目已经包含了所有必需的 PNG 图像和清单文件。

需要注意的是，evaluate 脚本会在 development 集上调参并在固定的 test 集上评估；而 stress 脚本则是在参数选定后进行挑战性测试，其结果不应用于调参（这样才能保证验证的独立性）。

### 实验结果

所有实验结果都保存在 `results` 目录下，包括：

- 80 张合成图像（160 个实例）的精确率/召回率/F1 分数
- 不同模式下的计数平均绝对误差（MAE）
- 单图处理延迟统计
- 40 张倾斜遮挡挑战图像的测试结果
- 10 项签到系统功能检查
- 二维码图像解码验证

关于上游项目 DeepFace 的启动问题、数据库操作顺序以及人为同步并发的审计记录，可以查看 `audit` 目录。我们没有发布上游项目识别准确率的复现结果。

如果你想验证并发竞态条件的反例，可以先获取原仓库，然后运行：

```bash
python scripts/upstream_race.py --upstream-src /path/to/original/repo/src
```

该脚本仅导入数据库模块进行测试，不包含上游源代码。

## 数据与隐私保护

### 系统设计理念

本系统的视觉处理仅用于检测人脸位置，不会进行人脸识别、特征比对、模板提取或跨帧跟踪。系统不用于成绩评定、纪律处分、雇佣决策等高影响场景。

### 数据采集与处理

- 照片和摄像头数据完全由操作者自愿提供，系统不会自动采集
- 图片仅在内存中处理，用户界面只显示全画面马赛克效果
- 签到台账不保存原始图片或人脸模板
- 马赛克处理并非绝对的匿名化保障，仍可能存在漏检或误检情况

### 实验数据说明

项目使用的实验数据来自一张 NASA 公有领域源照片的合成变体。development 和 test 数据集共享相同的源人脸，仅用于受控的工程验证，无法证明系统在跨人群、自然场景下的泛化能力。stress 测试主要展示系统的失败边界。

需要特别说明的是，本项目没有进行真人试点测试，不提供活体检测、身份认证或防代签保障。

### 本地运行与安全

运行时数据（`runtime` 目录）包含数据库文件和首次生成的密钥（权限设置为 0600），请勿上传到公共平台。活动内代号的 HMAC 摘要是可关联的假名数据，而非完全不可逆的匿名化处理；相同代号在不同活动中会使用不同的 HMAC 输入。如果密钥丢失，旧的二维码和摘要将无法验证。

本系统仅适用于单机可信操作者场景，未实现账号权限管理、分布式并发控制、API 限流或完整的安全审计机制。

### 图表生成

重新生成实验结果图表：

```bash

```

生成的图表将保存在 `results/figures` 目录。如果不指定中文字体路径，可能会出现字符显示不全的情况，建议指定本机已授权的中文字体文件。
